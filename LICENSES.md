Each package's full licence text is in its folder under `node_modules` once installed. `xlsx` (SheetJS, 0.18.x) is used only at build time by the baseline and demographics packages to read ABS and VEC workbooks; it is never imported by the web app or in the built site. It has an open advisory (prototype pollution and ReDoS in the npm release), which matters only if untrusted workbooks are read; ours are the official ABS and VEC files.

The test and build tools (Vite, Vitest, TypeScript, ESLint, Playwright and their dependencies) are used to build the site and are not part of it.
